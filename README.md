# Between あいだ

Appareil photo slit-scan pour le navigateur, inspiré de *async – immersion* (Ryuichi Sakamoto + Shiro Takatani).

Une ligne de pixels balaie l'image : chaque colonne est saisie à un instant différent, et la photo garde la trace d'un temps long.

- **Balayage** : la ligne parcourt le cadre, chaque colonne à son instant.
- **Fente** : une fente fixe au centre, le temps défile sur la largeur.
- **Pose longue** : images superposées (moyenne, éclaircir, assombrir).

Réglages : durée, format, sens, teinte (couleur, noir et blanc, async), définition, objectif, zoom, exposition, retardateur, vidéo du balayage.

Tout se passe sur le téléphone : aucune image n'est envoyée nulle part.
